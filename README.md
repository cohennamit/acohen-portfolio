# 💻 Amit Cohen — Interactive Developer Portfolio

A modern, fully responsive personal portfolio and interactive system designed to showcase my academic background in Computer Science, specialized career tracks, and production-grade software projects. 

Built with a focus on clean UI/UX, modular component architecture, smooth animations, and bidirectional track-to-project navigation.

---

## ✨ Key Features

* **Modular Career Tracks:** Interactive cards highlighting specialized domains (**Software Development**, **Machine Learning & AI**, **DevOps & Systems**, and **Networks**), complete with relevant coursework, grades, and track-specific CV downloads.
* **Bidirectional Project Integration:** Clicking any project pill inside a career track seamlessly switches tabs, smooth-scrolls to the exact project card, and highlights it with a glowing focus state.
* **Dynamic GitHub Redirection:** Direct repository routing for major projects with built-in fallbacks to my main GitHub profile.
* **Fully Responsive Design:** Crafted with **Tailwind CSS** to ensure a flawless presentation across mobile devices, tablets, and desktop screens.
* **Smooth Animations:** Powered by **Framer Motion** for sleek, modern transitions and state changes.

---

## 🛠️ Built With

* **Framework:** Next.js / React
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
